# Foodiee UI/UX

**A complete food-delivery app and web design system, from splash screen to live order tracking.**

Foodiee is a UI/UX case study for a Zomato or Swiggy-style food ordering platform. It covers the customer app, delivery-partner (rider) app, restaurant-partner app, desktop web pages, an admin dashboard and a full design system. The visual language pairs a deep plum with blaze orange and saffron gold.

> Design only. These are static screens, not a working app.

## Design language

| Token | Value | Use |
|---|---|---|
| Blaze orange | `#FF6B1A` | Primary actions, highlights |
| Amber | `#FFA13D` | Gradients, secondary accents |
| Saffron gold | `#FFC857` | Tags, premium (Gold) |
| Deep plum | `#1F0F2E` | Text, dark surfaces |
| Violet | `#5B2A86` | Gradient depth, wallet and cards |
| Mint | `#0B7A62` | Ratings, success states |
| Blush | `#FFF6EE` | App background |

**Typography:** Bricolage Grotesque (display and headings) and Plus Jakarta Sans (body).
**Shape:** 12 px, 24 px and pill radii with soft plum shadows.
**Imagery:** original vector food illustrations (pizza, burger, biryani, dosa, lava cake, momos). Swap in real photography for production.

## Feature highlights

- **Core ordering:** location, search, filters, restaurant menu, dish customisation, cart, checkout, order placed, live tracking.
- **UPI-first payments:** UPI app list, UPI ID verification, PIN approval, awaiting approval, failure and retry, wallet.
- **Growth features:** group ordering with bill split, Foodiee Gold membership, table booking, quick bites (10 minutes), referrals, coupons, spin and win.
- **Smart discovery:** AI meal assistant, voice search, photo search, healthy picks with nutrition, food reels, scheduled orders.
- **Delivery moments:** rider chat, tip your rider, cancel and refund status.
- **Complete states:** empty cart, no results, no internet, kitchen closed, loading skeleton, maintenance, dark mode.
- **Ecosystem:** restaurant partner app, rider app, admin dashboard.
- **Design system:** style guide, components and brand pages.
